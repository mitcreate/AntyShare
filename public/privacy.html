Privacy Policy

Our core architectural commitment: We do not store, inspect, or retain your files. Your transfers remain direct and private.

Last Updated: October 2026 • Effective Immediately

⚠️ Crucial Advisory: Non-Sensitive Media Only

AntyShare is architected strictly for casual media, photos, audio, videos, documents, and developer packages. You must never use AntyShare to transfer confidential financial records, credit card numbers, passwords, government-issued IDs, or sensitive personal data. While transfer streams utilize encryption, peer-to-peer sharing requires mutual trust between communicating endpoints.

1. The Strict 100% Zero-Server Storage Principle

AntyShare operates on an absolute Zero-Storage Architecture. Unlike traditional cloud drives or file lockers (such as Google Drive, WeTransfer, or Dropbox):

  • No File Uploads or Server Disks: Files are never uploaded to, saved on, or cached across our web servers or proxy databases. All historical server-side upload directories and disk-write endpoints have been permanently decommissioned and purged.
  • Direct Memory-to-Memory Streaming: In Offline Hotspot and Quick Wi-Fi Radar modes, data streams directly over your local network interfaces via high-speed memory buffers directly into the recipient's browser Downloads.
  • DTLS-SRTP Encrypted P2P: In Global P2P mode, files stream directly between browser endpoints using WebRTC DataChannels secured by DTLS-SRTP encryption. The server merely facilitates initial session negotiation (SDP handshake) and never touches payload bytes.
Summary: As soon as the transfer finishes or a browser tab is closed, all transfer states immediately vanish from memory. 0 MB and 0 bytes remain on any remote infrastructure.

2. Information We Process & Privacy Protections

A. Ephemeral Signaling Data (Discarded Instantly)

When connecting peers in Global Room mode or Local Radar mode, our signaling relay briefly passes:

  • Temporary WebSocket session identifiers.
  • Ephemeral WebRTC ICE candidates and Session Description Protocol (SDP) exchange objects.
  • Randomly generated 6-digit room codes or LAN discovery beacons.

This signaling metadata is held purely in volatile server memory (RAM) for the duration of socket connection and is purged the instant peers disconnect.

B. Public IP Masking & Anonymity

To preserve your privacy on shared networks, AntyShare enforces public IP masking. On the Quick Wi-Fi Radar mesh, device IP addresses are masked (e.g. 103.112.***.*** or labeled Local Wi-Fi Network). Your true public IP address is never revealed to other peers or displayed in the UI.

C. 1-to-1 Room Lock & Anti-Brute-Force Rate Limiting

Each Global P2P room is strictly limited to exactly two peers (1 sender and 1 receiver). Any third device attempting to enter an active room is automatically rejected with a ROOM_FULL security block. Furthermore, code submission endpoints enforce strict rate-limiting (max 6 attempts per 30 seconds) to prevent automated brute-force attacks.

3. Zero Trackers, Zero Ads & No User Profiling

AntyShare is proud to operate a 100% tracker-free and advertising-free platform:

  • No Advertising Networks: We do not run Google AdSense or any third-party programmatic ad networks. Your screen is never cluttered with intrusive commercial banners or popups.
  • No Tracking Cookies or Pixels: We do not use marketing trackers, Facebook Pixels, or cross-site tracking beacons.
  • No Personal Profiling: We do not monetize user behaviors, inspect file filenames, or build behavioral profiles.

4. Local Storage and Client Cache (PWA)

AntyShare uses your browser's localStorage solely to save your local UI preferences:

  • Selected color theme (Dark / Light mode).
  • Custom device display name (e.g. "Arjun's Phone") for Radar identification.
  • Service Worker assets (HTML/CSS/JS) cached strictly for offline application launch.

No transferred files, tokens, or personal identifiers are stored in localStorage or IndexedDB.

5. Enterprise Data Security Measures

  • Transport Layer Security: All signaling traffic, web assets, and API handshakes are encrypted using TLS 1.3 / HTTPS.
  • DTLS & SRTP End-to-End Encryption: All peer-to-peer WebRTC transfers enforce standard DTLS encryption with AES-128 or AES-256 GCM cipher suites.
  • Automated Executable / Script Warning: When an incoming transfer contains an executable or script (.exe, .bat, .cmd, .msi, .apk, .vbs), the recipient is presented with a real-time amber security alert badge before acceptance.
  • Camera Hardware Sensor Release: The QR scanner camera stream is immediately closed and powered off by hardware release the moment a QR code is read or dismissed.
  • No Account Required: AntyShare requires zero registration, zero email addresses, and zero phone numbers. You remain completely anonymous.

6. GDPR & CCPA Privacy Rights

Under the European General Data Protection Regulation (GDPR) and California Consumer Privacy Act (CCPA), users possess rights to access, rectify, or delete personal data. Because AntyShare retains zero user accounts, zero profiles, and zero file storage, we do not hold identifiable personal data to retrieve or erase.

7. Children's Privacy

AntyShare does not knowingly collect or solicit any personal information from children under the age of 13. If you believe a child has provided personal information to our site, please contact us immediately.

8. Changes to this Privacy Policy

We may periodically update this Privacy Policy to reflect technical improvements or legal requirements. Updated policies will be posted on this page with a revised "Last Updated" timestamp.
