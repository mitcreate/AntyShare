Frequently Asked Questions (FAQ)

1. Does AntyShare save or store my transferred files?

No. AntyShare operates on an absolute Zero-Storage Architecture. Files are streamed directly between peer memory buffers or local network interfaces. We do not maintain any persistent storage disk array for user files. The moment your transfer is finished or your session is closed, all traces vanish.

2. Why is there a warning against sharing sensitive information?

AntyShare was engineered from the ground up for high-speed transfer of everyday media, creative video edits, photography galleries, archives, and developer packages. Because transfers happen directly between peers without server verification or identity vetting, you should never use this platform to send sensitive documents such as banking credentials, passwords, confidential corporate trade secrets, or national ID cards.

3. How fast can AntyShare transfer files in Offline Hotspot mode?

In Offline Hotspot mode (or 5 GHz local Wi-Fi), file streaming bypasses the public internet entirely. Transfer speeds depend solely on your device Wi-Fi chips, typically reaching between 40 MB/s and 90 MB/s (up to 700 Mbps). A 10 GB file can transfer in under 3 minutes.

4. Is there any file size limit?

No artificial file size restrictions are imposed by AntyShare. Users routinely transfer files from 500 MB to 50 GB. In Global P2P mode, maximum file size may only be bounded by your browser's available RAM and WebRTC buffer capacity.

5. How does the Offline Hotspot mode work with zero internet data?

Once you install AntyShare as a Progressive Web App (PWA) on your phone or laptop, all HTML, CSS, and client-side JavaScript assets are cached locally by your browser's Service Worker. You can turn off mobile data completely, connect both devices to the same personal Wi-Fi hotspot, and transfer directly over local TCP sockets without consuming a single byte of cellular data.

6. What security and privacy protections are built into AntyShare?

AntyShare enforces enterprise-grade privacy and defense-in-depth across every transfer mode:

  • 100% Zero-Storage Architecture: Files stream purely memory-to-memory. No file data is ever written to disk or stored on our servers.
  • End-to-End DTLS-SRTP Encryption: Direct peer channels use bank-grade AES-128/256-GCM encryption.
  • Public IP Masking: Device IPs on the radar mesh are automatically masked to safeguard your location and network identity.
  • 1-to-1 Room Locking & Rate Limiting: Global transfer rooms strictly reject third-party interlopers and rate-limit code guessing.
  • Automated Executable Malware Scan: Incoming executable and script files (.exe, .bat, .cmd, .msi, .apk) trigger a bright security warning alert before you accept.
  • 100% Ad-Free & Tracker-Free: Zero commercial advertisements, zero Google AdSense, zero tracking cookies, and zero user accounts.
