# Contributing to AntyShare

Thank you for your interest in contributing to **AntyShare**! AntyShare is an open-source, zero-storage, peer-to-peer (P2P) file transfer platform. We welcome contributions from developers, designers, and testers of all skill levels.

---

## 🛠️ Development Setup

1. **Fork and Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/AntyShare.git
   cd AntyShare
   ```

2. **Install Node.js dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm start
   # Access at http://localhost:8000
   ```

---

## 🤝 How You Can Contribute

* **WebRTC & Streaming Performance:** Optimize memory buffering and chunk streaming for multi-gigabyte transfers.
* **Mobile & Android Enhancement:** Improve foreground service stability during background transfers in the Android app.
* **Security Audits:** Help inspect WebRTC DTLS-SRTP implementations and rate-limiting routines.
* **UI/UX Polish:** Enhance responsive design and offline PWA service worker caching.
* **Bug Reports & Feature Requests:** Open an issue on GitHub with details and reproduction steps.

---

## 📋 Pull Request (PR) Guidelines

1. Create a feature branch: `git checkout -b feature/your-feature-name`
2. Keep code clean, readable, and well-commented.
3. Test changes locally on both browser and local network.
4. Push to your branch and submit a Pull Request describing your changes and motivations.

---

## 📄 Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free environment for everyone. Please be respectful and constructive in all discussions and code reviews.
